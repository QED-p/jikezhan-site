# 前言：读之前先对一遍账

这一组文章从零开始讲线性代数，不假设你学过大学课程. 但"从零"不等于"什么都不需要"——下面把入口条件和记号约定一次说清，省得读到一半卡在奇怪的地方.

## 会用到、但会现场补的

- 求和号 $\sum$：第一次出现时会展开写，不熟也不影响.
- 逻辑符号 $\forall$（对任意）、$\implies$（推出）：正文一律配中文解释.
- 集合记号 $\{\cdot\}$、$\in$、$\subseteq$：同上.

## 符号约定

全组统一，遇到新记号会先定义再使用.

**向量**：粗体小写，如 $\mathbf{u}, \mathbf{v}, \mathbf{w}$；基向量用 $\mathbf{e}_1, \mathbf{e}_2$（标准基）或 $\mathbf{b}_1, \dots, \mathbf{b}_n$（一般基）；坐标写成列向量，分量是不带粗体的斜体，如 $x, y, u^i$.

**矩阵**：大写字母 $A, B, M$；元素 $a_{ij}$ 表示第 $i$ 行第 $j$ 列；单位矩阵记 $I$；转置记 $A^{\mathsf{T}}$；行列式记 $\det A$. 对角矩阵（非对角线元素全为零的方阵）记 $\operatorname{diag}(d_1, \dots, d_n)$，其中 $d_1, \dots, d_n$ 依次摆在主对角线上. 例如 $\operatorname{diag}(2,1) = \begin{bmatrix} 2 & 0 \\ 0 & 1 \end{bmatrix}$.

**内积与投影**：内积记 $\langle \mathbf{u}, \mathbf{v} \rangle$；标准内积在 $\mathbb{R}^n$ 上可以写成 $\mathbf{x}^{\mathsf{T}}\mathbf{y}$（为什么能这样写，第 4 章给理由）；投影记 $\operatorname{proj}_{\mathbf{u}}\mathbf{v}$.

**空间与集合**：$\mathbb{R}$ 是实数，$\mathbb{R}^2$ 是平面，$\mathbb{R}^n$ 是 $n$ 维坐标空间；张成记 $\operatorname{span}\{\mathbf{v}_1, \dots, \mathbf{v}_k\}$；维数记 $\dim V$.

**标点**：句号一律用半角英文句点——写 `这样.`，不写 `这样。`；其余标点（逗号、分号、冒号、问号）用全角. 这是全站的统一风格，公式内部的标点随 LaTeX 保持半角. 看到"哪里.这"连着写，不是排版事故.

## 怎么读

- 每章结构固定：动机 → 定义与例子 → 可拖动的实验 → 习题（答案折叠）. 定义先于使用，证明能折叠就折叠——先看结论，需要时再展开.
- 每章开头的"高中那点工具"会声明这一章要用到哪些已知内容；章节表里的"前置"标的是最小依赖，不是要求你把前面的全部学完.
- 实验是动手环节，至少要拖一遍：这条线上的直觉基本都长在鼠标上.
- 哪段读不懂，别硬盯定义——找两三个具体的数代进去，把式子手算一遍. 抽象概念几乎都能被一个 2×2 或 3×3 的例子拆开.
